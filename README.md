## 🏗️ What I'm Building

### [`nlp-labs-vietnam/ios-design-system`](https://github.com/nlp-labs-vietnam/ios-design-system)
> Pure iOS Human Interface Design System for Web & Modern Frameworks — Lightweight, Zero-drift, Token-driven

A Turborepo monorepo (`pnpm` workspaces) delivering `@alisababivip/*` packages across:

```
packages/tokens  → CSS Variables + JSON Design Tokens
packages/icons   → SVG Icons + SF Symbols + Animations
packages/core    → Web Components (framework-agnostic CSS)
packages/react   → React wrapper components
packages/vue     → Vue 3 wrapper components
packages/blade   → Laravel Blade bridge
apps/docs        → VitePress documentation
apps/showcase    → iOS Simulator preview (Vite)
```

### [`nlp-labs-vietnam/investment-platform`](https://github.com/nlp-labs-vietnam)
> AI-driven investment intelligence engine — real-time NLP sentiment analysis for financial markets

Core stack: Apache Kafka · RabbitMQ · Fine-tuned Transformer models · RAG (Milvus/Pinecone) · gRPC/WebSocket APIs
